## Cart Service

| Method | Endpoint | Origin | Description |
|--------|----------|--------|-------------|
| **GET** | `${import.meta.env.VITE_CART_SERVICE_URL || 'http://localhost:3003'}/api/cart/${userId}` | `src/pages/Cart.jsx` | Retrieve the current user's cart contents. |
| **GET** | `${CART_SERVICE_URL}/api/cart/${userId}` | `src/pages/Cart.jsx` | Same as above (different constant naming). |
| **POST** | `${import.meta.env.VITE_CART_SERVICE_URL || 'http://localhost:3003'}/api/cart/${user.userId}/items` | `src/pages/ProductList.jsx` & `src/pages/ProductDetails.jsx` | Add a product to the user's cart. |
| **DELETE** | `${CART_SERVICE_URL}/api/cart/${userId}/items/${productId}` | `src/pages/Cart.jsx` | Remove a specific item from the cart. |
| **DELETE** | `${CART_SERVICE_URL}/api/cart/${userId}` | `src/pages/Cart.jsx` | Clear the entire cart (e.g., after checkout). |
